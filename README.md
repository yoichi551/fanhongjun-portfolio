## 🚀 使用方式

### 克隆到本地
```bash
git clone https://github.com/<你的用户名>/fanhongjun-portfolio.git
cd fanhongjun-portfolio
```

### 每周更新流程（建议）
```bash
# 1. 拉取远端最新版本
git pull origin main

# 2. 在对应 WeekXX 文件夹下编写 / 上传作业

# 3. 提交并推送
git add .
git commit -m "Week05: 完成数据结构实验报告"
git push origin main
```
